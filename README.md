Bem-vindo à organização oficial do projeto desenvolvido para a **Global Solution 2026 (1º Semestre)** do curso de Engenharia de Software da FIAP.

## 🚀 O Desafio e a Solução
Nosso projeto conecta a infraestrutura da **Indústria Espacial (Constelação Starlink)** à malha urbana para resolver um problema crítico na Terra: o tempo de resposta de ambulâncias em cruzamentos. 

Utilizando comunicação satelital de baixa latência e sistemas preditivos, o sistema automatiza a abertura de semáforos em cascata, eliminando a dependência de sensores físicos locais e atuação manual.
